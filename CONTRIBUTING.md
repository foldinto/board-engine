# Contributing / 参与贡献

Thank you for helping improve Foldinto Board Engine. You can write issues and pull requests in English or Simplified Chinese.

## Workflow

1. For substantial changes, open an issue or start a discussion first so we can agree on the problem and scope.
2. Fork the repository, make a focused change, and run `node --test test-board.cjs`.
3. Open a pull request describing the problem, the change, and test results. Maintainers will review it and decide whether to merge; a submission does not guarantee acceptance.
4. Do not include secrets, personal information, internal documents, or material you lack permission to share.

Disclose any third-party code, assets, or dependencies and their licenses before submitting. If contributing for an employer or another organization, ensure you have its permission.
